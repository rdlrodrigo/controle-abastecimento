Configurar Google Apps Script
Para gravar novos abastecimentos diretamente na planilha Google Sheets, instale o backend (Code.gs) e cole a URL do Web App abaixo.
1. Abra a planilha → Extensões → Apps Script
2. Cole o conteúdo do arquivo Code.gs (disponível para download)
3. Execute a função setupPlanilha() uma única vez
4. Clique em Implantar → Nova implantação → Aplicativo da Web
   • Executar como: Eu (minha conta)
   • Quem tem acesso: Qualquer pessoa
5. Copie a URL gerada e cole no campo abaixo
